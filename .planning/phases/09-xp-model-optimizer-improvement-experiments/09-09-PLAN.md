## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fotmob.com unofficial endpoints -> pipeline | reverse-engineered JSON with no stability contract and no schema guarantee |
| fbref.com via a local browser -> pipeline | a Cloudflare-protected site scraped through a locally installed Chrome |
| match-outcome statistic -> pre-match feature | the boundary that decides whether the join is enrichment or a leak |
