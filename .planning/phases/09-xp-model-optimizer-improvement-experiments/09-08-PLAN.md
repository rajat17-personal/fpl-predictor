Run the first third of D-01's experiment 6: join Understat's non-penalty xG and involvement-chain metrics as rolled features.

Purpose: this project already carries FPL's own xG and xA. Understat adds the non-penalty separation and the involvement-in-move metrics FPL's feed lacks, and OpenFPL's published result — position-specific ensembles trained on FPL plus Understat data alone matching FPL Review's accuracy — is the reason this source is worth the join at all. Output: `data/understat.py` with a cache, a rate limit and a kill switch; the shared crosswalk extended with the name fixups Understat needs; new rolled feature columns; a leakage assertion; and an adoption verdict in IMPROVEMENTS.md.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| understat.com -> pipeline | a third-party community source whose payload shape carries no stability contract |
| match-outcome statistic -> pre-match feature | the boundary that decides whether this join is enrichment or a leak |
| name-keyed join -> canonical table | a many-to-many name match would multiply every training row |

No new packages are installed in this plan; `understatapi` is already pinned in `requirements.in`.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
