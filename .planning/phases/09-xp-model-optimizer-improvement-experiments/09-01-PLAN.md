<objective>
Build the shared experiment spine that all six of this phase's experiments ride on, and prove it end-to-end by putting the cheapest real experiment (captaincy ceiling EV, quantile variant) through it.

Purpose: D-07/D-08 require every experiment to land opt-in behind a flag, be A/B-measured by `backtest/walk_forward.py`, and have its number recorded. Today there is no flag registry, no way to run a season subset for fast iteration (D-14), and no tagged result artifact — so every later experiment would invent its own ad-hoc switch. Build it once, here.

Output: an `EXPERIMENTS` flag registry in `config.py`, a season/flag/tag-aware `backtest/walk_forward.py` CLI, `models/captaincy.py` producing a leakage-safe `xp_capt_ceiling` armband column, an unattended-run launcher (D-15), a regression test file, and the re-measured 6-season baseline written into `IMPROVEMENTS.md`.
</objective>
