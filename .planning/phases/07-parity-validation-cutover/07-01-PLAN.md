<objective>
Build the production serving seam that makes side-by-side validation possible, and prove it
end-to-end by machine-comparing one real page across both live sites.

Purpose: Phase 5's D-06 promised cutover as "a config/env flip". Today that flip does not
exist — the React build is only servable in fixture mode, which also swaps to frozen data and
therefore cannot be the side-by-side vehicle. This plan builds the flip, the two-process
runner that uses it, and the thinnest honest proof that both processes are serving the same
live export. Everything else in Phase 7 stands on this.

Output: `FPL_FRONTEND=react` branch in `api/main.py`; `scripts/dual_site.sh`;
`e2e/parity/parity-diff.mjs` (one page); `tests/test_react_seam.py`; a react-mode container
assertion in `scripts/smoke_test.sh` wired into the CI docker job.
