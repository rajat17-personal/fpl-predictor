<objective>
Run the last of the three cycle-stage passes — the finished gameweek with the scoreboard scored —
and close the cycle out into a decision-ready evidence artifact.

Purpose: this is the stage that makes the report complete. It exercises the final standings, the
settled squad points and, for the first time in this cycle, a scoreboard page with a real scored
entry rather than an empty one. When it closes, `PARITY-REPORT.md` either says zero unexplained
deltas remain or it does not — and that sentence is what 07-06's human gate decides from.

Output: a completed post-finish stage table, every carry-forward closed, and a cutover-readiness
block computed from the three stage tables.

**Calendar-gated.** Task 1 carries a `<precondition>` that only becomes true once the validation
gameweek has finished and the daily scoreboard step has scored it. If it is not yet true, the
executor halts with a blocking-human checkpoint; resume when the scoreboard entry exists.
</objective>

plan, so it carries more unknown than the other seven pages. That is a stated risk, not a defect.
