`predict.live._gw_pool` when fixture mode is on but never restores it when the env var is unset

for the rest of the process, and `api.main`'s own re-import at line 44 pulls the already-polluted
value back in. Independently reproduced in 04-REVIEW.md (CR-01) and again in 04-VERIFICATION.md.

behaves exactly as it does today" (plan 04-01) — which currently reads FALSE. The seam is D-01's
one production-file change; this makes its OFF path as honest as its ON path (D-10's frozen-pool
bypass is unchanged).

Output: a capture-once production reference plus an explicit else-branch restore in `api/main.py`,
and a `tests/test_fixture_mode.py` that both tells the truth about its own teardown and fails if
this regression ever returns.
