<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → repo | a new devDependency and a downloaded browser binary enter the build |
| Playwright process → host ports | webServer binds local ports and spawns uvicorn |
| browser → test origin | every request the app makes during a run |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-SC | Tampering | `npm install @playwright/test`, `playwright install chromium` | high | mitigate | Blocking human package-legitimacy checkpoint (Task 1) with a registry re-check immediately before install, `--save-exact` pin, committed lockfile, and a single-package install surface |
| T-04-06 | Spoofing | `reuseExistingServer` adopting an unrelated local server | medium | mitigate | Port block starts at 8100, deliberately not the 8000 a developer's own uvicorn uses; the smoke spec asserts frozen-fixture values, so an adopted live server fails immediately rather than passing on real data |
| T-04-07 | Information Disclosure | Playwright HTML report and traces | low | accept | Report output is gitignored (`e2e/playwright-report/`, `e2e/test-results/`) and contains only committed fixture data |
| T-04-08 | Denial of Service | real ILP solves inside a browser test | low | accept | Per-test timeouts bound every run; the plan-flow test raises its own timeout locally rather than the global one, so a genuinely hung test is still caught |
</threat_model>

<flagged_assumptions>
- **Edge probe E2E-01 / concurrency — resolved explicitly.** "If interrupted or run in parallel, what is guaranteed?" One uvicorn serves the whole run and its pool and solve caches persist across specs; that is safe because the frozen pool is immutable within a run and `_solve_cache` keys on a sha1 of the entire request body plus gameweek. The corresponding acceptance criterion is the full non-variant suite passing with Playwright's default parallel workers (verify command 3 of Task 3). If an interrupted run leaves a stale uvicorn on the port block, `reuseExistingServer` adopts it — still a fixture-mode server, so results stay correct.
- `page.clock.setFixedTime` is assumed to leave React's own `setInterval` scheduling intact while freezing `Date.now`. If a countdown assertion proves flaky, the fallback is to assert the banner's gameweek segment only and record the reduction in the SUMMARY — do not reach for a fixed sleep.
</flagged_assumptions>
