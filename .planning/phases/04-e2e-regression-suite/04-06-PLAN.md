## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query parameter → `/api/rate/{entry}` | a user-controlled entry id reaches a solver endpoint |
| frozen manager summary → rendered heading | captured third-party-shaped personal fields become page content |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-21 | Tampering | entry id from the URL query reaching the rate endpoint | medium | mitigate | Team.tsx's parseEntry rejects non-numeric and non-positive values before any fetch; this spec asserts the no-entry prompt and the server-side 404 path, so neither a malformed nor an unknown id reaches a rendered traceback |
| T-04-22 | Information Disclosure | manager name and rank rendered in the heading | high | mitigate | The rendered values come from plan 04-01's checkpoint-approved capture policy; this spec asserts exactly what that policy left in the fixture, so a later widening of the captured fields fails the assertion rather than passing silently |
| T-04-23 | Denial of Service | the rating running two ILP solves per request | low | accept | Bounded by the per-test timeout; the rating runs on a frozen single-gameweek pool and completes in seconds |
| T-04-24 | Tampering | the swap line and the best-move tile disagreeing | low | mitigate | The spec asserts both against the same captured response, so a divergence between the two renderings fails |
</threat_model>
