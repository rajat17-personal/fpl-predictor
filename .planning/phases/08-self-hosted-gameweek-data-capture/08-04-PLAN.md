<objective>
Make the demotion of the previous source real in code, and write down how the new arrangement is
operated.

Purpose: plan 08-03 captured the data, but the ingestion module still believes it owns the current
season's three files. Its re-download flag would replace a full three-gameweek capture with the
single gameweek the previous source published — a one-command, silent regression. The runbook exists
because the next person to touch this, including the author in six months, will not remember which
source owns which season.

Output: a guarded `data/ingest.py`, its regression test, and
`docs/runbooks/gameweek-data-capture.md`.

This plan contains no tracer task. The phase's tracer is 08-01 Task 1; this is the expansion that
closes the ownership boundary around it.
</objective>
