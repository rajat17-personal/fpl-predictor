conventions that decide whether the output is consumable or silently useless.

architectural answer on the first commit.

`season_dir(season=None)` resolves `config.RAW_DIR / (season or config.CURRENT_SEASON)` at call

file goes in a `gws` child of it and is a bookkeeping artifact no consumer opens.

`_fetch_bootstrap(*, retries, backoff)` copies `data/snapshot.py`'s retry helper in shape: a
bounded attempt loop, a retryable status raised as an `HTTPError` so it lands in the same handler,
an immediate non-retried raise for a non-retryable 4xx, an exponential backoff with jitter between
attempts, and a `report(_JOB, "fetch", ...)` call immediately before the final re-raise so the
failure both alerts and exits non-zero.

`finished_gws(boot)` returns the sorted event ids for which the payload reports the event both
finished and data-checked. Both conditions, not just the first: an event can flip to finished
before its bonus points and stats are settled, and a row captured in that window is wrong in a way
no later run would notice, because the ledger file would already exist.

`fetch_history(pid)` GETs `element-summary/{pid}/` with the module user-agent and a 20-second
timeout and returns the `history` list. `sweep_histories(ids, *, sleep)` loops it with the
per-player try/except from `data/live_history.py` — one player's transport failure warns and
continues rather than aborting the sweep — and prints a progress line every 100 players.

`build_gw_frame(histories, boot, gw)` is the pure transform and the heart of this task. Keep the
rows whose `round` equals `gw`. Every one of the 41 history keys is copied through under its own
name — there are no renames on this side of the boundary. Add `GW` as a copy of `round`. Join
`name` as the element's `first_name`, a single space, and `second_name`. Join `team` by mapping the
element's numeric `team` through `teams[].name` — the full club name, which is the key
`data/odds.py` and `build_table.py`'s odds merge both spell out in full. Join `position` through
`_POS`. Emit `xP` as a missing value for now. Return the frame reindexed to `MERGED_GW_HEADER` so
the column set is the contract, not an accident of dict ordering.

`write_csv_atomic(df, path)` creates the parent directory, writes to a sibling temp file carrying
the process id in its suffix, `os.replace`s it into position, and on any exception removes the temp
file before re-raising. Every CSV this module ever writes goes through it.

`write_merged(season=None)` reads every `gws/gw*.csv` ledger file in the season directory,
concatenates them in gameweek order, and writes the result to the flat `merged_gw.csv` path
through `write_csv_atomic`. Regenerating from the ledger rather than appending is what makes a
re-run safe.

`capture(*, gws=None, force=False, retries=3, backoff=2.0)` fetches the bootstrap, resolves the
target gameweeks (the explicit list if given, else everything `finished_gws` reports), sweeps the
element ids, writes one ledger file per gameweek, regenerates the merged file, and returns a
summary dict of gameweek to row count. `main(argv=None)` is the argparse entry point with
`--force`, `--gw` accepting one or more integers, `--retries` and `--backoff`, ending in the
`sys.exit(main())` guard this repo uses everywhere.
