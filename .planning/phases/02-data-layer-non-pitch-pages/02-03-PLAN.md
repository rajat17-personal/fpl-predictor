<objective>
Build the two cross-page features this phase adds to the shared shell: the upgraded gameweek meta
banner chip with a live deadline countdown (UI-06), and the persistent three-state dark mode toggle
with its full dark token palette (UIX-02). Also complete D-12 by moving font delivery off the CDN.

Purpose: these are the only two genuinely new capabilities in an otherwise port-shaped phase — the
vanilla site has a static deadline chip and no theme control at all. The dark palette is
costly to reverse: Phase 3's pitch components will be written against these tokens, so the selector
strategy and the full semantic-colour coverage have to be right now rather than restructured later.

Output: `lib/theme.ts`, `lib/deadline.ts`, `components/ThemeToggle.tsx`, `components/GwBanner.tsx`,
a class-based dark token block in `index.css`, a pre-mount theme script in `index.html`, and
self-hosted font imports replacing the Phase 1 CDN stylesheet.
