<objective>
Build the test seam that every other API test in this milestone stands on, and prove it end to end
on the two endpoints that need it least — so the seam itself is validated before it carries weight.

`api/main.py` works today and this phase adds no production behaviour. What it lacks is a way to be
tested: `_state`, `_solve_cache`, and `_lock` are module-level globals, and `_refresh()` will
unconditionally `joblib.load(models/artifacts/xp_model.joblib)` the first time it runs. That file
exists on this machine but is **not tracked in git** and is now explicitly ignored by plan 01-01, so
any test that lets `_refresh()` run for real is coupled to a 7.1MB binary that will not exist when
Phase 5's CI checks out a clean tree.

Purpose: extract the one-line DI seam that makes state resettable, then prove the whole harness —
autouse reset, `_load_live` mock, artifact sentinel, `TestClient`, contract assertion — on
`/api/health` and `/api/meta` before extending it to the endpoints that solve ILPs and fetch squads.
Output: `_initial_state()` in `api/main.py`, `tests/conftest.py`, and the first contract tests in
`tests/test_api.py`.

**Explicitly out of scope here** (named so no executor treats them as oversights):
`CORSMiddleware(allow_origins=["*"])` stays exactly as it is — restricting it is Phase 6 `SEC-01`,
and the Vite dev proxy in plan 01-04 makes every browser request same-origin so CORS is never
consulted in that flow. The unlocked `_solve_cache` reads/writes stay exactly as they are — bounding
and locking that cache is Phase 6 `REL-05`.
</objective>
