<objective>
Harden the running API surface: restrict who may call it, bound and correctly invalidate the solve
cache, and make every request observable as one structured, secret-free JSON record.

Purpose: these are the three production-readiness gaps `CONCERNS.md` records against `api/main.py` —
an origin list that lets any website drive the solver, a cache that grows without bound and is read
outside the lock that clears it, and a service with no request trail at all. Phase 1 deliberately
wrote a concurrency test that documents the cache race without fixing it and named this phase's
REL-05 as its owner; this plan closes it.

Output: an origin list read from configuration with a wildcard treated as a boot failure, an
LRU-plus-TTL solve cache keyed on a monotonic pool version and touched only under the lock, and a
request-logging middleware that redacts every secret it could otherwise emit.
</objective>
