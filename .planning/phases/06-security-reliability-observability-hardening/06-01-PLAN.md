Create `ops/jsonio.py` exporting `PayloadError(RuntimeError)`, `read_json(path, *, what, remedy=None)`
and `write_json(obj, path, *, indent=None)`.

`read_json` must bind the file object with a `with` block using the builtin file-opening call in
its context-manager form (never the pathlib method form, and never as a bare expression handed
straight to `json.load`) with `encoding="utf-8"`, and hand that bound object to `json.load`. It
catches `FileNotFoundError` and `json.JSONDecodeError` and re-raises `PayloadError`. The message
must be one line and must carry, in this order: the `what` label, the absolute path, the concrete
cause (for a decode failure, `exc.msg` plus `exc.lineno` and `exc.colno`), and the `remedy` string
when one was supplied. A `PermissionError` or `IsADirectoryError` is also wrapped. Nothing else is
caught.

`write_json` must create a temporary file in the same directory as `path` (use
`tempfile.NamedTemporaryFile(dir=path.parent, delete=False)` or an explicit sibling `.tmp` name),
write the serialized payload into it inside a `with` block, then `os.replace(tmp, path)` so a
crash mid-write leaves the previous file whole and two concurrent writers cannot interleave. On
any exception it removes the temporary file before re-raising.

Create `ops/jsonlog.py` exporting `JsonFormatter`, `configure_logging(service, *, level, stream)`,
`log_event(logger, event, *, level, **fields)` and `redact(value)`.

`JsonFormatter.format` emits exactly one `json.dumps` object per record, with keys `ts` (UTC
ISO-8601, seconds precision), `level`, `logger`, `service`, `event` and `msg`, plus any extra
fields the caller attached. `event` falls back to the record's logger name when the caller supplied
none. Values that are not JSON-serializable are coerced with `default=str` so a formatter failure
can never swallow a log line.

`configure_logging` installs one `StreamHandler` (default stream `sys.stderr`) carrying
`JsonFormatter` on the root logger and must be idempotent: tag the handler with a module-private
attribute and, on a second call, replace the tagged handler rather than appending a second one, so
uvicorn reloads and pytest re-imports do not multiply lines. It returns the configured `Logger`.

`redact` and the formatter together must guarantee no secret reaches a log line: any field whose
key case-insensitively contains one of `key`, `token`, `secret`, `password`, `authorization`,
`webhook` is replaced with the literal string `[redacted]`, and any string value that exactly
matches one of the comma-separated entries of the `FPL_API_KEYS` environment variable is replaced
with `[redacted]` regardless of its key.
