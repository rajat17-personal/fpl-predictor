## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub raw + contents API -> `data/external/fpl_core_insights/` | untrusted third-party CSV content crosses into a permanently committed, tracked artifact |
| vendor per-gameweek folder -> `data/availability.py` resolver | mis-dating a frozen folder turns post-deadline knowledge into a "pre-match" feature |
| the commit itself -> git history | permanent and effectively irreversible (D-05: costly) |

| T-10-06-02 | Tampering | vendor schema drift silently producing an all-NaN availability column | high | mitigate | `_reduce_gw_csv` raises `ValueError` naming every missing `_KEEP_COLS` member and the gameweek, per 10-RESEARCH.md Pitfall 2 |
| T-10-06-03 | Tampering | a vendor value disagreeing with reality, adopted unchecked | high | mitigate | `--verify` compares `status` and `chance_of_playing_next_round` against our own captures on the two overlapping days and prints an explicit AGREES/DISAGREES verdict plus a disagreement sample; the result is recorded in the README |
| T-10-06-04 | Legal/compliance | committing content whose license forbids redistribution | high | mitigate | blocking-human license checkpoint before any bulk fetch, decision recorded verbatim, posture written into the README's `## Attribution` |
