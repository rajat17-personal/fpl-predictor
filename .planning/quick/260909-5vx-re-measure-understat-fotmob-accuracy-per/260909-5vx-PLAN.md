<objective>
Re-measure the Phase 9 understat and fotmob xp_med accuracy A/B sliced by position
(GK/DEF/MID/FWD) and by enrichment coverage, with paired confidence intervals, and
record the honest verdict as an IMPROVEMENTS.md Phase F addendum.

Purpose: Phase 9 measured both sources pooled over all positions and all rows. The
model is per-position and the enrichment join is partial, so a real positional gain
could have been diluted twice over and rejected as noise. `understat` was the phase's
closest miss (model+chips 2278 vs the 2,280 bar), so this is worth one cheap
measurement pass before the leads are closed permanently.

Output: `backtest/enrichment_slices.py` (a reusable, cached, measurement-only module),
`data/processed/experiments/enrichment_position_coverage.json` (50 cells: 2 sources x
5 position slices x 5 coverage slices), and an IMPROVEMENTS.md addendum that inlines
the decisive numbers (the JSON lives under gitignored `data/processed/`, so the
committed record must carry the numbers themselves).

Non-goal: this plan adopts nothing and changes no default. If a position shows a real
covered-row gain, the addendum records it as a *motivated follow-up experiment*
(a per-position flag variant) under the existing D-07 adoption discipline — it does
not build that variant here.

and 97.5th percentiles of the delta. `signal` is True only when `d_mae_hi < 0.0` AND
`d_spearman_lo > 0.0` — i.e. both axes improved beyond their own interval. Round every
float to 4 decimals. Guard `n < MIN_CELL_N` and `n == 0`: return the full key set with
`signal` False and `note` naming the small-sample reason, skipping the bootstrap. Also
tolerate a degenerate constant column by treating a non-finite Spearman as 0.0 with a
`note`.
