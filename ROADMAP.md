# Product roadmap

The plan for turning this repo into a paid product, tracked honestly. Strategy
and market context live in the published playbook; this file is the working
checklist. Tier 3 items (live rank tracking, licensed Opta visuals, predicted
lineups, chat assistant, native apps) are deliberately out of scope until a
re-entry trigger fires — see the bottom.

## Phase A — productize the pipeline ✅ (2026-08-31)

- [x] `predict/export.py` — versioned JSON contract in `web/data/`
      (xp_table, captains, squad, fixtures ticker, chips, meta, frozen history)
- [x] `models/intervals.py` — empirical p10/p90 bands from held-out residuals
      (measured coverage 0.86 for a nominal 0.80 band — slightly conservative)
- [x] `predict/scoreboard.py` — post-GW scoring of frozen predictions vs actual
      and vs FPL's own ep_next; appends `web/data/scoreboard.json`
- [x] `data/snapshot.py` — daily bootstrap snapshot (**cron this first**; price
      history cannot be backfilled). First snapshot: 2026-08-31.
- [x] `scripts/daily.sh`, `scripts/weekly.sh` + `.github/workflows/` (dormant
      until the repo is pushed to GitHub)

## Phase B — free site ✅ code / ⏳ deployment

- [x] `web/` static site, framework-free (Cloudflare Pages-ready): xP table with
      uncertainty bands + sort/filter/search, fixture ticker (validated
      diverging palette), differentials with ownership slider, price watch,
      scoreboard with empty-state backtest tiles, methodology, rate-my-team
- [ ] Deploy `web/` to Cloudflare Pages + domain
- [ ] Email list + weekly digest sending (content is generated by
      `predict.digest`; pick Buttondown/SES once an account exists)
- [ ] Marketing loop: weekly chart/thread, r/FantasyPL (check self-promo rules
      with mods first), CSVs to creators

## Phase C — engagement models ✅ scaffold / ⏳ data

- [x] `models/price.py` — watchlist now reads **FPL's official price predictor**
      (2026/27 API fields: `price_change_percent`, projections, likelihood,
      locks) — ground truth, no reverse-engineering needed. The heuristic and
      the trainable model remain as fallbacks; daily snapshots also archive the
      official fields for later analysis
- [x] Rate-my-team — `GET /api/rate/{entry}`: score vs ILP optimum + best move
- [ ] Publish price-model hit-rate on the scoreboard once trained

## Phase D — paid product ✅ engine / ⏳ auth+payments (user finalizing)

- [x] `api/main.py` — FastAPI: `/api/team/{entry}`, `/api/solve` (locks,
      excludes, horizon 1–6, chip modes, from-scratch or transfer mode, cached
      per gameweek+params), `/api/rate/{entry}`; hourly pool cache
- [x] Entitlement stub — `FPL_API_KEYS` env → `X-API-Key`; single choke point
      (`require_key`) to swap for real auth
- [ ] Auth + subscriptions (Supabase magic links + `subscriptions` table,
      2-free-gameweeks counter) — **blocked on payment-stack decision**
- [ ] Payments (Razorpay pages + Paddle/Dodo checkout → webhooks) — **blocked
      on the same decision**
- [ ] Planner UI page (interactive lock/exclude/re-solve, savable drafts) —
      build once auth exists to attach drafts to
- [ ] Hetzner deploy + deadline-hour load test

## Phase E — pre-launch hardening (Apr–Jun 2027)

- [ ] Cron failure alerts to email; DB backups; staging
- [ ] ToS / privacy / refund pages (required by payment providers)
- [ ] CA consult: 44AD vs 44ADA; GST registration only past ₹20L/yr
- [ ] Pre-GW1 early-bird season pass to the email list

## Tier 3 — future scope, with re-entry triggers

| Feature | Trigger to reconsider |
|---|---|
| Live in-match rank tracking | subscribers rank it #1 in a feature vote |
| Opta-grade stats/visuals | revenue justifies a Stats Perform licence |
| Predicted lineups / team news | content partnership exists |
| Chat assistant over the JSON | >500 subscribers ask for it |
| Native mobile apps | responsive site measurably loses mobile users |

## Operating notes

- All FPL API access goes through cached modules — never hammer the API from
  user requests; the pool refreshes at most hourly.
- Every bound list or fallback says so in its JSON (`mode: "heuristic"`), and
  the page must render that label.
- No bookmaker/real-money-gaming affiliates, ever (Online Gaming Act 2025).
  No PL branding. "Not affiliated" footer on every page.
